# 知识库数据留存与脱敏规范（清单 112）

> 适用范围：元矩阵知识库（目录树、页面属性、评论、分享、在线协作状态、导入导出与审计事件）。
> 目标：既能排查问题，又不让敏感数据在日志、导出包和事件表里扩散。

## 1. 数据分类

| 类别 | 例子 | 留存期限 | 存放位置 |
| --- | --- | --- | --- |
| 业务内容 | 文档正文、附件、表格、导图 | 与空间生命周期一致，删除即进回收站，超期自动清理 | `canvas_documents`、`knowledge_node_data`、媒体目录 |
| 元数据 | 标题、摘要、标签、属性、版本快照 | 同上；版本按 `KNOWLEDGE_VERSION_KEEP`（默认 50 条）滚动淘汰 | `doc_properties`、`knowledge_doc_versions` |
| 协作痕迹 | 评论、@提及、表情回应 | 与文档一致；评论随文档删除 | `doc_comments` |
| 访问凭证 | 分享 token、访问口令 | 口令只存 SHA-256 摘要；token 有效期默认永久，可随时撤销 | `knowledge_shares` |
| 瞬时状态 | 在线协作者、光标位置 | 进程内存，TTL 过期自动剔除，不落库 | `PresenceRegistry` |
| 审计事件 | 谁在何时访问/导出/修改 | 长期保留，导出时脱敏 | `knowledge_events` |

## 2. 脱敏规则

1. **分享 token**：审计事件只写前 6 位 + `********`（`maskShareToken`）。事件表会被导出，token 等同访问凭证。
2. **访问口令**：服务端只保存 `SHA-256(pwd + 固定盐)`，任何接口都不回显明文，也不记录到日志。
3. **敏感正文**：保存与导入时扫描身份证号、手机号、密码等特征（`ScanSensitive`），命中时提示作者脱敏。
4. **导出内容**：整空间 zip 导出包含正文与附件，属高敏感操作，写入 `knowledge_events`（`export` 类型），并在活动面板可见。
5. **在线协作状态**：只保存在进程内存，不落库、不进日志、不进导出包。

## 3. 访问控制

- 节点级可见范围：`visibility=private` + `allowed_users`，子节点沿父链继承最严格范围（`nodeVisible`）。
- 分享白名单：`knowledge_shares.allow_users` 非空时，只有名单内成员（登录态）能打开分享页，匿名访问返回 403。
- 回收站：软删除进回收站，保留 `KNOWLEDGE_TRASH_KEEP_DAYS`（默认 30 天）后由定时任务清除。

## 4. 审计要求

| 动作 | 事件类型 | 记录内容 |
| --- | --- | --- |
| 新建/修改/移动/删除节点 | `node.create` / `node.update` / `node.move` / `node.delete` | 节点 ID、操作者 |
| 发布文档 | `doc.publish` | 文档 ID、操作者 |
| 新增评论 | `comment.create` | 文档 ID、操作者 |
| 通过链接访问 | `share.access` | 脱敏 token、操作者 |
| 导出（空间包 / docx） | `export` | 导出对象 |

## 5. 定期动作

- 每日：清理超期回收站节点（定时任务，6 小时轮询）。
- 每周：检查版本表容量，超过保留条数的旧快照自动淘汰。
- 按需：对导出包做敏感扫描后再对外分发。
