# 富文本与飞书文档的差距

更新日期：2026-11-02。对照的是日常写作体验，不是飞书品牌或素材。实时协同、无限画布不在范围内。

编辑器已按界面拆开：工具栏、正文区和弹层分别是 `RteToolbar.vue`、`RteDocumentBody.vue`、`RtePortals.vue`，命令和状态仍留在根组件。这一轮在拆分之后补上可解决的评论线程和建议模式，并修掉新文档占位行上 End、Enter、`/` 被画布回写打乱斜杠菜单的问题。

## 已经有的

- 飞书式主工具栏、选区气泡、斜杠命令（中英文检索）、快捷键帮助
- 标题、列表、任务、引用嵌套、分割线、折叠块、高亮提示、分栏、日期、公式
- 表格插入、合并、列宽、制表符粘贴
- 图片与附件 3MB 上限、链接气泡、查找替换
- 大纲、块拖拽、块菜单、代码块语言与复制
- Markdown / 纯文本 / HTML 复制、打印与 PDF
- 只读预览、源码、暗色编辑区
- 页面大小：宽度 100%（默认）、飞书阅读宽度、A3 / A4 / A5 / 8K / B5 / Letter。存在画布 JSON 的 `pageSizeByPanelId`，按面板 id 保存
- 工具栏按功能分成多枚彩色胶囊（操作、文字、颜色、段落、链接、表格、块级、批注、审阅、导出），可整组拖拽，顺序存在 `toolbarGroupOrderByPanelId`。未归类按钮才进「其他」，不再合成一个「更多」大组
- 图片组：拖到另一张图或图片组的左右边缘并排（2 张及以上，等高、按比例分宽），组内可改顺序和宽度比例，拖出或「拆分为单图」后还原成独立图片，只剩一张时自动解散。整组可在块之间拖动，可左中右对齐，且不超过页面宽度。旧的纯图片分栏会迁成图片组。比例和结构写在正文 HTML 里
- 页眉、页脚、页码：底栏可改页眉页脚，页码可选「1 / 第 n 页 / 第 n 页 共 m 页 / - n -」。按面板存在 `pageChromeByPanelId`，旧文档缺省为空、不占版心。编辑、最大化、只读、打印预览用同一套边距；打印每页重复页眉页脚，页码用页计数；PDF 每页盖上页眉和对应页码
- 演示模式：全屏只读翻页，可按块或按屏（标题另起一屏）。Esc 或「退出」回到进入前的编辑/预览状态。不是实时协同，也不是无限画布
- 评论线程：选中文字后评论，可回复、解决、重新打开、删除自己的发言。侧栏列出未解决的线程，点条目跳回正文锚点；已解决默认不显示。正文只留 `data-comment-thread` 锚点，讨论存在画布 JSON 的 `commentThreadsByPanelId`，按面板 id 保存，不另建表。旧的行内批注仍留在正文里
- 建议模式：工具栏「建议」在直接编辑和修订之间切换。建议模式下的插入和删除带作者与时间，按人着色；可接受或拒绝单条和全部。只读预览、打印和 PDF 只显示接受后的正文，不带修订标记

## 仍缺，留给后续轮次

1. 服务端版本历史。现在只有本次会话里的本地记录，刷新即失。
2. 组织目录里的真人 @，以及按文档权限过滤。现在的提及是本文标题、块和本地候选人。
3. 跨文档同步块、跨文档搜索。
4. 大文档虚拟化。长文只是放慢了大纲扫描，输入本身仍由编辑器整篇重绘。
5. 移动端手势：块拖拽、表格和工具栏在窄屏上仍然偏挤。
6. 投票、思维笔记、多维表格、文档内嵌白板。这些不属于当前 TipTap 面板。
7. 分享链接、水印、对外权限。属于文档产品，不是编辑器内核。
8. 根文件仍集中编辑器生命周期、命令和工具目录。样式在 `pros/web/src/components/rte/styles/`。工具栏、正文区和弹层通过 `provideRteBindings` 读写原来的 ref 和函数；scoped 样式靠 `data-rte-own` 补上根组件的 `data-v`。评论线程和建议模式已经接在正文区里，版本历史、@ 真人、虚拟化和移动端仍未做。

明确不做：多人实时光标、无限画布、按画布类型拆业务表。
