# 富文本与飞书文档的差距

更新日期：2026-11-02（第二轮）。对照的是日常写作体验，不是飞书品牌或素材。实时协同、无限画布不在范围内。

编辑器已按界面拆开：工具栏、正文区和弹层分别是 `RteToolbar.vue`、`RteDocumentBody.vue`、`RtePortals.vue`，命令和状态仍留在根组件。这一轮在拆分之后补上可解决的评论线程和建议模式，并修掉新文档占位行上 End、Enter、`/` 被画布回写打乱斜杠菜单的问题。

## 已经有的

- 飞书式主工具栏、选区气泡、斜杠命令（中英文检索）、快捷键帮助
- 标题、列表、任务、引用嵌套、分割线、折叠块、高亮提示、分栏、日期、公式
- 表格插入、合并、列宽、制表符粘贴
- 图片与附件 3MB 上限、链接气泡、查找替换
- 大纲、块拖拽、块菜单、代码块语言与复制
- Markdown / 纯文本 / HTML 复制、打印与 PDF
- 只读预览、源码、暗色编辑区
- 页面大小：宽度 100%（默认）、飞书阅读宽度、A3 / A4 / A5 / 8K / B5 / Letter。存在画布 JSON 的 `pageSizeByPanelId`，按面板 id 保存
- 工具栏按功能分成多枚彩色胶囊（操作、文字、颜色、段落、链接、表格、块级、批注、审阅、导出），可整组拖拽，顺序存在 `toolbarGroupOrderByPanelId`。未归类按钮才进「其他」，不再合成一个「更多」大组
- 图片组：拖到另一张图或图片组的左右边缘并排（2 张及以上，等高、按比例分宽），组内可改顺序和宽度比例，拖出或「拆分为单图」后还原成独立图片，只剩一张时自动解散。整组可在块之间拖动，可左中右对齐，且不超过页面宽度。旧的纯图片分栏会迁成图片组。比例和结构写在正文 HTML 里
- 页眉、页脚、页码：底栏可改页眉页脚，页码可选「1 / 第 n 页 / 第 n 页 共 m 页 / - n -」。按面板存在 `pageChromeByPanelId`，旧文档缺省为空、不占版心。编辑、最大化、只读、打印预览用同一套边距；打印每页重复页眉页脚，页码用页计数；PDF 每页盖上页眉和对应页码
- 演示模式：全屏只读翻页，可按块或按屏（标题另起一屏）。Esc 或「退出」回到进入前的编辑/预览状态。不是实时协同，也不是无限画布
- 评论线程：选中文字后评论，可回复、解决、重新打开、删除自己的发言。侧栏列出未解决的线程，点条目跳回正文锚点；已解决默认不显示。正文只留 `data-comment-thread` 锚点，讨论存在画布 JSON 的 `commentThreadsByPanelId`，按面板 id 保存，不另建表。旧的行内批注仍留在正文里
- 建议模式：工具栏「建议」在直接编辑和修订之间切换。建议模式下的插入和删除带作者与时间，按人着色；可接受或拒绝单条和全部。只读预览、打印和 PDF 只显示接受后的正文，不带修订标记
- 正文版本：底栏「版本」列出自动记录和命名版本，可恢复。恢复前先把当前正文记成一版。按面板存在 `editorRevisionsByPanelId`，随画布文档保存，刷新后还在。自动记录最多 15 次，命名版本最多 8 个；单版正文超过 12 万字符时不写入，编辑不受影响。不是独立版本服务，也没有按人对照的差异
- 对齐菜单和「首行」按钮可给当前段落加 2 字首行缩进。列表菜单可继续上一个有序列表的编号、从 1 重新开始、修改起始值，也可改成数字、字母或罗马数字。插入「按钮」只做打开 http(s) 链接，可改文字和蓝、绿、橙、红、灰五种颜色；创建副本和关注文档不做
- 真人 @：@ 菜单优先列组织通讯录里的人（`api/directory.listDirectoryUsers`，后端没实现该路由时回退到本地示例，不报错）。可按文档权限过滤：权限钩子写在画布 JSON 的 `mentionPermissionByPanelId`，按面板保存；工具栏「@权限」里按部门、角色勾选，不勾表示不额外限制。斜杠菜单有「提及某人」入口。检索支持中文、拼音首字母与全拼
- 斜杠菜单：记录最近使用（本地保留 5 条，空查询时置顶成「最近使用」分组），支持中文、拼音首字母与全拼检索，命中越直接排越前
- 选区气泡：除加粗、斜体等格式外，可「复制选中文字」「把选中文字变成链接」「把选中文字转成表格」（按行拆行、按制表符拆列）、「改写选区」（清理空格 / 中英文空格 / 合并短行三条本地规则；AI 服务未接入，这里是 stub）
- 工具栏：右键任一分组可打开「组内按钮」面板，勾选显隐、箭头调顺序，按面板存在 `toolbarGroupButtonsByPanelId`，旧文档缺省等于分组默认顺序、全部显示。收起态的「更多」菜单按同一套配置渲染
- 查找替换：除区分大小写、全词匹配外，支持正则与多行；正则非法时按「没有匹配」处理，不报错
- 表格单元格公式：表格右键菜单有「插入公式」（写 `=SUM(ABOVE)` 模板）与「计算公式」。支持 `SUM/AVERAGE/COUNT/MAX/MIN`、`ABOVE`、`LEFT`、区域（如 `A1:B3`）与算术混排。算完后单元格显示结果，公式原文留在单元格的 `data-formula`，可以再算
- 图片：气泡里可裁剪（原始 / 1:1 / 4:3 / 3:4 / 16:9 / 9:16）、写替代文字（alt，给读屏与图片检索用）。换图会带上裁剪参数。裁剪参数存在图片节点的 `data-crop-*` 上
- 列表：菜单新增「从此处重编号」，把有序列表在当前项处切成两段，当前项及之后从 1 重新编号，前半段保持原编号
- 大纲：条目右键可「跳到这一节」「复制标题」「复制标题链接」
- 跨文档：工具栏「跨文档」按标题或正文搜索本账号可见的其它文档，点标题跳过去（hash 路由），点「插入同步块」把来源文档的正文快照插成本文的一个同步块（`syncBlock` 节点，存来源与快照，点来源跳转）。同步是快照 + 手动插入，不是后台自动同步
- 页面设置：底栏新增「页面设置」入口，把页面大小、页边距、页眉、页脚、页码收在一个面板里改；底栏原有的行内输入仍保留
- 移动端：窄屏（≤720px）出现底部浮动条，放加粗、斜体、列表、链接、@、评论和更多入口，避免窄屏把工具栏挤在一起
- 只读预览：右侧浮层列出未解决的评论，点条目跳到正文锚点，跟随正文滚动

## 仍缺，留给后续轮次

1. 大文档虚拟化（本轮延期）。编辑器仍是一篇文档一个 ProseMirror 实例、整篇渲染，画布面板也是按整段 HTML 回写。要虚拟化就得把长文拆成多个编辑器实例，那会连带破坏评论锚点、交叉引用、版本快照和画布回写，回归面过大。本轮只做到长文不再拖慢大纲扫描。
2. 真人 @ 的后端还没实现 `/directory/users`，真人列表目前由前端示例兜底；权限只能按部门、角色过滤，没有按文档成员名单过滤。
3. 跨文档同步块是「快照 + 手动插入」，没有后台定时同步或推送；同步块也不引用来源里的具体块级锚点。
4. 移动端只做了窄屏浮动条，长按、双指缩放、块拖拽等手势没做；窄屏下表格和工具栏仍然偏挤。
5. 图片组整组的左中右对齐已有，组内留白（图片之间的间距可调）没做。
6. 表格公式只覆盖常用函数与区域引用，不支持跨表引用，也不支持单元格命名。
7. 投票、思维笔记、多维表格、文档内嵌白板。这些不属于当前 TipTap 面板。
8. 分享链接、水印、对外权限。属于文档产品，不是编辑器内核。
9. 根文件仍集中编辑器生命周期、命令和工具目录。样式在 `pros/web/src/components/rte/styles/`。工具栏、正文区和弹层通过 `provideRteBindings` 读写原来的 ref 和函数；scoped 样式靠 `data-rte-own` 补上根组件的 `data-v`。评论线程、建议模式、正文版本、真人 @、跨文档和组内按钮配置都已经接上。

明确不做：多人实时光标、无限画布、按画布类型拆业务表。
