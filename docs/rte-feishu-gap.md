# 富文本与飞书文档的差距

更新日期：2026-11-02。对照的是日常写作体验，不是飞书品牌或素材。实时协同、无限画布不在范围内。

第十一轮先把图片排版对齐飞书的图片组（并排、拆分、调比例、整组拖动）。下面 1–10 仍未做。第 11 项已把编辑器按界面拆开，命令和状态仍留在根组件。

## 已经有的

- 飞书式主工具栏、选区气泡、斜杠命令（中英文检索）、快捷键帮助
- 标题、列表、任务、引用嵌套、分割线、折叠块、高亮提示、分栏、日期、公式
- 表格插入、合并、列宽、制表符粘贴
- 图片与附件 3MB 上限、链接气泡、查找替换
- 大纲、块拖拽、块菜单、代码块语言与复制
- Markdown / 纯文本 / HTML 复制、打印与 PDF
- 只读预览、源码、暗色编辑区
- 页面大小：宽度 100%（默认）、飞书阅读宽度、A3 / A4 / A5 / 8K / B5 / Letter。存在画布 JSON 的 `pageSizeByPanelId`，按面板 id 保存
- 工具栏按功能分成多枚彩色胶囊（操作、文字、颜色、段落、链接、表格、块级、批注、审阅、导出），可整组拖拽，顺序存在 `toolbarGroupOrderByPanelId`。未归类按钮才进「其他」，不再合成一个「更多」大组
- 图片组：拖到另一张图或图片组的左右边缘并排（2 张及以上，等高、按比例分宽），组内可改顺序和宽度比例，拖出或「拆分为单图」后还原成独立图片，只剩一张时自动解散。整组可在块之间拖动，可左中右对齐，且不超过页面宽度。旧的纯图片分栏会迁成图片组。比例和结构写在正文 HTML 里

## 仍缺，留给后续轮次

1. 服务端版本历史。现在只有本次会话里的本地记录，刷新即失。
2. 可解决的评论线程。现在的批注留在正文 HTML 里，没有讨论和解决状态。
3. 组织目录里的真人 @，以及按文档权限过滤。现在的提及是本文标题、块和本地候选人。
4. 跨文档同步块、跨文档搜索。
5. 建议模式 / 完整修订（接受、拒绝、按人着色）。现有修订高亮不是一条修订流。
6. 演示模式、页眉页脚、页码。页面大小已能按纸张打印，但没有页眉页脚。
7. 大文档虚拟化。长文只是放慢了大纲扫描，输入本身仍由编辑器整篇重绘。
8. 移动端手势：块拖拽、表格和工具栏在窄屏上仍然偏挤。
9. 投票、思维笔记、多维表格、文档内嵌白板。这些不属于当前 TipTap 面板。
10. 分享链接、水印、对外权限。属于文档产品，不是编辑器内核。
11. `RichTextEditor.vue` 已从约 1.6 万行拆到约 5900 行。样式在 `pros/web/src/components/rte/styles/`（scoped 与 Teleport 全局各一份，选择器未改）。工具栏、正文区（气泡、画布、大纲、底栏）和各类 Teleport 弹层分别是 `RteToolbar.vue`、`RteDocumentBody.vue`、`RtePortals.vue`。子组件通过 `provideRteBindings` 读写原来的 ref 和函数，对外 props / emits 不变；scoped 样式靠 `data-rte-own` 补上根组件的 `data-v`。根文件仍集中编辑器生命周期、命令和工具目录，评论、版本历史、@ 真人、建议模式、虚拟化和移动端都不在这次拆分里。

明确不做：多人实时光标、无限画布、按画布类型拆业务表。
