# 表格公式栏

更新日期：2026-11-04。对应 P1 需求「表格公式栏」：选中表格单元格时，编辑器浮出一条公式栏，显示单元格地址和原始公式/值，可以直接改并回写。

## 是什么

- 选中表格里的单元格（文本光标落在单元格里，或多选单元格）时，正文区上方浮出公式栏
- 公式栏左边是单元格地址（`A1` 风格，第 1 列第 1 行是 `A1`），右边是输入框，输入框里是**原始公式或原始值**
- 输入框右边显示计算结果；出错时显示错误码（`#REF!` / `#VALUE!` / `#DIV/0!` / `#NAME?`）
- 选区离开表格，公式栏自动隐藏；只读（预览）模式下不显示
- 回车或点「应用」把输入写回单元格，并重算整张表

## 支持的写法

| 写法 | 例子 | 说明 |
| --- | --- | --- |
| 聚合函数 | `=SUM(A1:B3)`、`=AVERAGE(A1:B3)` | `SUM` / `AVERAGE` / `COUNT` / `MAX` / `MIN` |
| 多参数 | `=SUM(A1,A2)` | 逗号分隔 |
| 相对区域 | `=SUM(ABOVE)`、`=SUM(LEFT)` | 当前格上方 / 左方的连续单元格 |
| 单元格引用 | `=B2*3`、`=B2+1`、`=B2-1`、`=B2/2` | 引用其它单元格 |
| 区域算术 | `=SUM(A1:B2)*2` | 函数结果参与运算 |
| 百分号 | `=50%+1` | 百分数按小数算 |
| 千分位 | `=1,200+1` | 输入的数字可以带千分位逗号 |

公式单元格可以引用另一个公式单元格，会递归求值。

## 错误码

| 错误码 | 含义 |
| --- | --- |
| `#REF!` | 引用无效（地址越界、地址非法）或**循环引用** |
| `#VALUE!` | 操作数不是数值，或公式语法非法 |
| `#DIV/0!` | 除数为 0；`AVERAGE` 没有任何可参与计算的数字 |
| `#NAME?` | 未知函数名 |

错误码既写进单元格，也显示在公式栏上。

## 数据落在哪

- 单元格显示**计算结果**，公式原文存在单元格的 `data-formula` 属性上（`RteTableCell` 的 `formula` 属性）
- 重新选中该单元格时，公式栏显示的仍是公式原文，可以继续改
- 输入不以 `=` 开头的内容按普通文本处理，同时清掉该单元格的 `data-formula`

## 已知限制

- 不支持跨表引用，也不支持单元格命名（`=Sheet2!A1`、`=总计` 不支持）
- 公式栏挂在正文区组件上，凡是挂了完整富文本编辑器的地方（正文、画布内嵌的富文本区块）都会出现
- 公式栏浮在表格上方，表格在视口外时会贴到画布左上角兜底位置
- 单元格里的自定义属性（背景色、边框色等）在 HTML 序列化时仍会丢失，这是既有问题，本次只修了 `data-formula`
