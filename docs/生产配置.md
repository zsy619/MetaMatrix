# 生产配置与快捷键

上线前核对下面几项。计数和限流都在进程内存里，不新建业务表。

## JWT_SECRET

`JWT_SECRET` 必须换成足够长的随机值，不要使用仓库里的开发默认值。令牌为 HS256，有效期 7 天。剩余不足 24 小时且令牌仍有效时，客户端会调用 `POST /auth/refresh` 续期。已过期的令牌会被拒绝，需要重新登录。

## CORS

`CORS_ORIGINS` 是逗号分隔的允许来源。不要写成 `*`：通配符会被忽略，并退回本地开发源 `http://localhost:5173` 与 `http://127.0.0.1:5173`。只填写实际的前端地址。

## 登录限流

| 变量 | 默认 | 含义 |
| --- | --- | --- |
| `LOGIN_WINDOW` | `15m` | 滑动窗口，至少 1 分钟 |
| `LOGIN_PAIR_LIMIT` | `8` | 同一 IP + 邮箱的失败次数上限 |
| `LOGIN_IP_LIMIT` | `30` | 同一 IP 的失败次数上限 |

超过上限返回 `429`，`code` 为 `rate_limited`，并带 `Retry-After`。成功登录只清掉该邮箱的计数。

## 分享链接

当前文档接口都要求登录，并且只允许访问本人的画布。公开只读链接会新增一条未登录访问路径，本阶段不做。

## 工作面板统计

`GET /documents/stats` 只统计当前登录用户。查询参数 `scope` 不会放宽范围。响应异常或字段缺失时，页面会把数字补成 0，而不是整页失败。导出 CSV 在浏览器里生成，内容就是当前屏上的趋势，不另建表。

## 一键启动

在仓库根目录：

```bash
docker compose up --build
```

这会启动 Postgres 16（宿主机 `5433`）、API（`3000`）和网页（`8080`）。网页把 `/api` 转到 API。`GET http://localhost:3000/health` 与容器健康检查相同：数据库可连时 `200` / `ok`，否则 `503` / `degraded`。

只在本机跑 Go、单独起数据库时，仍用 `pros/api/docker-compose.yml`。不要同时占用同一个 `5433` 端口。

`JWT_SECRET` 在 Compose 里默认为开发值。上线前用环境变量换成随机长字符串。`CORS_ORIGINS` 默认是 `http://localhost:8080`，要和网页实际来源一致。

## 备份

账户页可以下载本人未归档画布的 JSON 包（最多 200 份），再导入为新画布，不会覆盖原件。单次导入最多 50 份。整库用：

```bash
docker compose exec postgres pg_dump -U metamatrix metamatrix > metamatrix.sql
docker compose exec -T postgres psql -U metamatrix metamatrix < metamatrix.sql
```

## 缓存

`GET /documents`、`GET /documents/:id` 和备份接口是 `Cache-Control: private, no-store`。统计接口是 `private, max-age=20`。浏览器里的统计缓存按用户 id 分开，退出登录会清掉。

## 依赖

直接依赖的 KaTeX 是 `0.19.1`。Mermaid `11.17.2` 自带一份 `katex@0.16.47`，只给图里的公式用。现有版本范围内没有单独的安全升级可做，这一批不改编辑器依赖，避免整包重编译带来不确定的画布变化。

## 健康检查与指标

`GET /health` 探测数据库。正常为 `200` / `ok`，数据库不可用为 `503` / `degraded`，并带上运行时长和请求分档。Compose 里的 API 健康检查打的就是这个地址。

`GET /metrics` 是 Prometheus 文本。访问日志里的 `request_id` 与错误 JSON 的 `requestId` 相同。如果调用方传入合法的 `traceparent`，访问日志会一并记下。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| Ctrl 或 ⌘ + S | 保存当前画布 |
| Esc | 关闭最大化面板、资料预览或版本对话框。同一时间只有一个面板可以最大化 |
| Alt + 1 | 回到模板库 |
| Alt + 2 | 打开工作面板 |
| ? | 打开或关闭快捷键说明 |

在输入框、文本区或正文编辑器里，除保存以外的快捷键不会触发。
