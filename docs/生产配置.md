# 生产配置与快捷键

上线前核对下面几项。计数和限流都在进程内存里，不新建业务表。

## JWT_SECRET

`JWT_SECRET` 必须换成足够长的随机值，不要使用仓库里的开发默认值。令牌为 HS256，有效期 7 天。剩余不足 24 小时且令牌仍有效时，客户端会调用 `POST /auth/refresh` 续期。已过期的令牌会被拒绝，需要重新登录。

## CORS

`CORS_ORIGINS` 是逗号分隔的允许来源。不要写成 `*`：通配符会被忽略，并退回本地开发源 `http://localhost:5173` 与 `http://127.0.0.1:5173`。只填写实际的前端地址。

## 登录限流

| 变量 | 默认 | 含义 |
| --- | --- | --- |
| `LOGIN_WINDOW` | `15m` | 滑动窗口，至少 1 分钟 |
| `LOGIN_PAIR_LIMIT` | `8` | 同一 IP + 邮箱的失败次数上限 |
| `LOGIN_IP_LIMIT` | `30` | 同一 IP 的失败次数上限 |

超过上限返回 `429`，`code` 为 `rate_limited`，并带 `Retry-After`。成功登录只清掉该邮箱的计数。

## 健康检查与指标

`GET /health` 探测数据库。正常为 `200` / `ok`，数据库不可用为 `503` / `degraded`，并带上运行时长和请求分档。

`GET /metrics` 是 Prometheus 文本。访问日志里的 `request_id` 与错误 JSON 的 `requestId` 相同。如果调用方传入合法的 `traceparent`，访问日志会一并记下。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| Ctrl 或 ⌘ + S | 保存当前画布 |
| Esc | 关闭最大化面板、资料预览或版本对话框。同一时间只有一个面板可以最大化 |
| Alt + 1 | 回到模板库 |
| Alt + 2 | 打开工作面板 |
| ? | 打开或关闭快捷键说明 |

在输入框、文本区或正文编辑器里，除保存以外的快捷键不会触发。
