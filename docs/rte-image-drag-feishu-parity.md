# 飞书文档图片拖拽对照

依据飞书帮助中心《在文档中插入、编辑图片》：同一行只放图片时等高；拖到另一张图的左边或右边并排；拖分栏线或四角调整大小；删除后其余图片仍等高；桌面/网页一行最多 **10** 张。块移动用左侧六点手柄。本表是编辑器对照，勾选表示本轮已实现并在下面的自测里覆盖。

- [x] 1. 单图悬停左侧六点手柄，拖到任意段落之间，出现蓝色横线，松手成为独立一行
- [x] 2. 拖到另一张单图或组内任意图的左/右边缘，蓝色竖线，松手插入该行的行首、行中或行尾
- [x] 3. 组内拖动按左右边缘重排顺序
- [x] 4. 从一行拖到另一行；源组只剩一张时还原成单图，空组删除
- [x] 5. 从组内拖到上下方，脱离成单独一行
- [x] 6. 整组用工具条上的手柄拖到其他块之间
- [x] 7. 一行最多 10 张（飞书桌面/网页的上限）；超出时提示「一行最多 10 张图片」，不插入
- [x] 8. 分隔条在间隙里，悬停才显示；拖动写入自定义比例；双击恢复按宽高比
- [x] 9. 拖拽时原图半透明，光标旁有缩略图，靠近画布上下边缘自动滚动，并显示蓝色落点线
- [x] 10. 并排等高、按宽高比分宽、间距 8px、整行铺满
- [x] 11. 单图和组内图都可选中后缩放（组内拖四角会记成比例）、对齐、题注、删除、下载、查看大图；拖文件到图片中间替换
- [x] 12. 选中图片或图片组后，Delete / Backspace 删除；方向键移动选区（左右相邻图，上下换行）
- [x] 13. 上述排版步骤进入撤销栈，Ctrl+Z / Ctrl+Shift+Z 逐步还原
- [x] 14. 把本地图片文件拖到某张图的左/右边缘，直接插入该行，而不是替换
- [x] 15. 只读预览、打印、PDF 使用同一组 HTML/比例，预览里不能拖；旧的纯图片分栏仍迁成图片组

未照搬的部分：移动端不支持并排（飞书本身也不支持）；文字和图片同行仍走分栏，不混进图片组。
