# 元矩阵 · 全局设计规范（Telegram Web K）

> **状态：全局唯一规范，优先级最高。**
> 参考实现：[Telegram Web K（morethanwords/tweb）](https://github.com/morethanwords/tweb)。
> 代码落地：`pros/web/src/styles/telegram.css`（`main.ts` 最后导入，覆盖 `glass.css` / `enterprise.css` 的旧规则）。
> 后续所有新页面、新弹窗、新组件一律按本规范实现；如需偏离，必须在 PR 描述里写明原因。

---

## 1. 设计原则

| 原则 | 落地要求 |
|---|---|
| 轻量、快速、平台原生 | 不用重投影、重渐变；表面以「白底 + 发丝线」分层 |
| 克制的主色 | 品牌蓝只用于主按钮、选中态、可点击文本 |
| 紧凑但有呼吸 | 列表行 28–34px，弹窗正文 16–20px 内边距，行距 1.5 |
| 状态即时可见 | 任何交互都要有 hover / active / focus 三态 |
| 内容优先 | 正文纸面不透明白（长文、表格、画布），玻璃只用于外壳 |

---

## 2. 色彩

| 令牌 | 值 | 用途 |
|---|---|---|
| `--tg-blue` | `#3390ec` | 主按钮、选中态、可点击文本、聚焦环 |
| `--tg-blue-hover` / `--tg-blue-active` | `#2b87dd` / `#2482d1` | 按钮悬停 / 按下 |
| `--tg-blue-soft` | `rgba(51,144,236,.12)` | 选中底色、浅色磁贴 |
| `--tg-green` / `--tg-red` / `--tg-yellow` / `--tg-purple` | `#4fae4e` / `#e53935` / `#f7bc2f` / `#8b5cf6` | 成功 / 危险 / 警告 / 分类语义 |
| `--tg-text` / `--tg-text-2` / `--tg-text-3` | `#0f0f0f` / `#707579` / `#8e8e8e` | 正文 / 次级 / 弱提示（对比度 ≥ 4.5:1） |
| `--tg-surface` / `--tg-surface-2` / `--tg-surface-3` | `#ffffff` / `#f4f4f5` / `#ececf1` | 主表面 / 次级填充 / hover 填充 |
| `--tg-border` / `--tg-border-strong` | `#e6e6e6` / `#d8d8dc` | 发丝线 / 强分隔 |

Element Plus 基线已被改写（`:root` 内 `--el-color-primary` 等），组件库默认即 Telegram 蓝。

## 3. 圆角与尺寸

| 元素 | 圆角 | 高度 |
|---|---|---|
| 弹窗 / 消息框 / 浮层面板 | `12px` | — |
| 下拉 / 气泡 / 选择器 | `12px`（内部项 `8px`） | — |
| 按钮 | `12px` | 32 / 36 / 40px（small / default / large） |
| 输入框 / 下拉选择 | `12px` | 36px |
| 卡片 / 磁贴 | `12–16px` | — |
| 分段控件 / 标签 / 计数徽标 | `999px`（药丸） | 24–32px |
| 图标磁贴 | `8–13px` | 24 / 34 / 42px |

---

## 4. 弹窗规范（本轮统一改造的全部弹出框）

- **遮罩**：`rgba(0,0,0,.45)` + `blur(3px)`，点击遮罩可关闭（除非是危险确认）。
- **容器**：纯白 `--tg-surface`，圆角 `12px`，投影 `0 24px 64px rgba(15,23,42,.18)`，**不做玻璃**（弹窗要压住背后内容）。
- **头部**：左对齐标题 `16px / 600`，**不加竖条装饰**；右侧关闭按钮 `28×28`、圆角 `8px`、hover 填充 `--tg-surface-2`；头尾之间一条 `--tg-border` 发丝线。
- **正文**：内边距 `16px 20px`，内容超高时内部滚动（`max-height: calc(100vh - 220px)`）。
- **底部动作区**：上边发丝线，按钮右对齐；主按钮实心蓝 `--tg-blue`，次按钮白底 + 发丝线；按钮圆角 `12px`、最小宽度 `88px`。
- **消息框（确认类）**：宽 `420px`，图标 + 标题 + 说明，底部 `取消` / `确定` 两键，`确定` 用蓝色（危险操作可保留红色语义色）。
- **抽屉**：白底，标题 15px/600，顶部发丝线。
- **自绘浮层**（面板最大化 `.pm-card`、RTE `.rte-modal`、版本历史、公式、附件预览、画布属性）一律套用同一套表面：白底 + `12px` 圆角 + 中性投影。

---

## 5. 表单与按钮

- 输入框：白底 + `1px` 发丝线（`inset`），聚焦时边框转 `--tg-blue` 且外扩 `3px` 的 `rgba(51,144,236,.16)` 光环；placeholder `--tg-text-3`。
- 复选框 / 单选 / 开关：选中态统一 `--tg-blue`；勾选框圆角 `6px`（Telegram 风格）。
- 文字按钮：文字 `--tg-blue`，hover 填充 `--tg-surface-2`。
- 分段控件：外层灰底容器（`rgba(15,23,42,.07)`，圆角 `999px`，内边距 `3px`），选中块为白色药丸 + 蓝色文字 + `0 1px 3px rgba(15,23,42,.16)` 阴影；**分段内的单项不再各自描边**，避免被看成多个独立按钮。

---

## 6. 反馈与动效

- 动效时长统一 `160ms`，缓动 `cubic-bezier(.2,.8,.3,1)`。
- hover 位移仅用于「可点击卡片 / 图标按钮」，位移 `1–2px`。
- `prefers-reduced-motion: reduce` 时关闭过渡与位移。
- 键盘可达：`:focus-visible` 使用 `2px` 品牌蓝外环；不要用 `outline: none` 一刀切（仅对分段控件的无障碍焦点例外恢复）。

---

## 7. 与玻璃拟态的关系

- 玻璃拟态（`styles/glass.css`）仍是**页面外壳**的材质方案：极光背景、侧栏、卡片外壳。
- **Telegram 规范负责所有「表面之上」的元素**：弹窗、消息框、浮层、下拉、表单、按钮。
- 冲突时 Telegram 规范优先（`telegram.css` 在 `main.ts` 最后导入）。
- 正文纸面（富文本正文、思维导图画布、多维表格内容区）保持不透明白，不套玻璃。
