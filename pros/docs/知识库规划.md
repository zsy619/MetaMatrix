# 知识库规划

飞书式知识库：目录树 + 富文本文档 + 画布嵌入 + 反向引用 + 大纲 + 导出 + 搜索 + 历史 + 模板。

## 分期

### 第一期 ✅ 已完成
- 目录树：`knowledge_nodes` 表（folder/doc），CRUD + 移动 + 环检测 + 级联删除
- 文档节点：`CreateDocWithNode` 一步建 doc（canvasType=doc）+ 挂节点
- 富文本编辑：`DocView.vue` 用 RichTextEditor，1.2s 防抖保存，409 重载
- 前端入口：`KnowledgeView.vue` 左树右编辑器，从项目详情进入

### 第二期 ✅ 已完成
- @ 文档 mention：`RteMentionKind` 加 `document`，候选源接知识树 + 项目文档
- 画布嵌入块：`canvasEmbed` TipTap 扩展，非 doc 文档插入只读引用卡片
- 反向引用索引：`page_references` 表，保存时扫描 mention/embed 重写索引，`GET /documents/:id/backrefs`
- 文档大纲：`DocOutline.vue` 从 HTML 抽 h1-h4，点击平滑滚动
- 导出：DocView 导出按钮，调 `exportDocument(id, 'markdown')`

### 第三期 ✅ 已完成（搜索/历史/模板）
- 全文搜索：`GET /documents/search?projectId=...` 限项目；KnowledgeTree 顶部搜索框，250ms 防抖，结果点击打开
- 版本历史：`DocHistory.vue` 列 `canvas_revisions`，materialize 恢复（覆盖当前 html + 防抖保存）
- 文档模板：`docTemplates.ts` 预设会议纪要/需求文档/周报，"+ 文档"下拉选模板，建空文档后 updateDocument 注入

### 第四期（规划）
- 协作：实时光标
- 文档分享：公开只读链接
- 导入：Markdown/Word 导入为文档
- 知识图谱：文档间关系可视化（基于 page_references）

## 数据模型

### knowledge_nodes（第一期）
- id, project_id, parent_id, node_type(folder/doc), document_id, title, sort_order, icon
- document_id ON DELETE SET NULL

### page_references（第二期）
- id, source_doc_id, target_doc_id, ref_type(mention/embed), target_label, created_at
- 保存时全量重建（删旧的再插新的），与 syncExtract 同事务
- 反查：SELECT source_doc_id FROM page_references WHERE target_doc_id = ?
