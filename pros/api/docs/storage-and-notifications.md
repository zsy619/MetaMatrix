# 附件存储与评论通知（C3 配置截止）

本文件记录功能分支上已经能安全落地的部分。下列事项**尚未验证**，不要当成已上线：

- 生产数据切换到真实 MinIO / S3
- 真实 SMTP 发信
- 跨实例 presence 共享（协同在线状态）

## 附件对象存储

- 运行时用 `MEDIA_STORE`：`disk` | `s3` | `auto`（默认 `auto`）。
- `auto` / `s3` 需要同时齐：端点、桶、访问密钥、秘密密钥；缺任何一项都回退本地磁盘，并在启动日志里写明原因。
- 代码已接 S3 兼容接口（含 MinIO）。**没有把已有生产附件迁过去。**
- S3 写入在可重放的流上遇到 429/5xx 或网络错误时最多再试两次；不能 Seek 且大于 8 MiB 的流不重试。

## 评论通知

- 新评论、回复、@ 会写站内通知。邮件通道未配置、SMTP 失败或被限流时，只记日志，评论写入与站内通知不回滚。
- 同一用户、同一条评论、同一通知类型不会重复写入站内通知（应用层幂等）。
- 邮件默认最多发送 2 次；同一收件地址在 1 分钟内最多 20 封（单进程内存限流，**跨实例不共享**）。

## Presence

跨实例 presence、生产 MinIO 切换、真实发信均标为未验证。
